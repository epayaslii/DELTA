UPC · IRI  —  Research briefing

Aligning DELTA

Learning to predict future actions by multimodal self-supervised learning. The near-term bet: fix the transcript → video temporal alignment that holds DELTA back on 50Salads, using vision-language foundation models and a self-supervised, structurally constrained alignment objective.

Base work DELTA (UPC-IRI) Datasets 50Salads → Breakfast This phase temporal alignment Date 2026-08-31

01 — The starting point

DELTA does dense anticipation from transcripts alone

Dense long-term action anticipation (DLTA) predicts a frame-level labelling of a future horizon. DELTA learns it from procedural transcripts — the ordered list of actions in a video, with no timestamps and no durations — instead of the dense frame labels every prior method needs.

A single shared encoder feeds three branches. A temporal alignment (TA) module grounds each transcript action in the video by dynamic programming over a boundary detector, producing dense pseudo-labels Y*. Those pseudo-labels are the only supervision that reaches a segmentation head (regularised by CTC for order-consistency) and a parallel anticipation decoder with a duration head and a linear-chain CRF. Text enters as DistilBERT action-name embeddings through locally masked cross-attention. Visual input is frozen I3D.

02 — The problem worth solving

On 50Salads, DELTA trails — and the paper says why

For contrast, on Breakfast DELTA matches or beats fully supervised methods (avg MoC ≈ 29–37 vs ActFusion 28.5). The gap is specific to 50Salads.

Why 50Salads is hard for transcript-only alignment

  • ~20 fine-grained action instances per ~6-minute video — a single misplaced boundary in Y* propagates into both the segmentation target and the future transcript T*.
  • 17 visually similar actions (cut_tomato, cut_cucumber, cut_cheese…) from one fixed top-down camera — I3D motion features under-separate them, so the boundary detector's posteriors are noisy exactly where it matters.
  • High intra-class duration variance — the duration head barely helps (+0.2 MoC on 50S vs +3.3 on BF).

Thesis. The bottleneck is the quality of the transcript → frame alignment, and that is dominated by how discriminative the frozen visual features are and by how the alignment is inferred. Both are addressable with vision-language foundation models and a differentiable, monotonicity-constrained alignment objective.

03 — Landscape

What the literature gives us to work with

Transcript-supervised segmentation

Ways to turn a noisy frame → label posterior into a monotone, transcript-consistent labelling. DELTA's TA is built on ATBA's boundary detector — the natural place to intervene. HAL is the strong recent baseline.

ECTC '16 · NN-Viterbi '18 · D³TW / CDFL '19 · MuCon '21 · ATBA (CVPR '24) · HAL (CVPR '26)

Self-supervised temporal alignment

Optimal transport with a temporal-consistency prior is now the best-practice replacement for greedy DP / Viterbi — and it is differentiable, so it can sit inside training. Ali et al. (ICCV '25) do alignment and segmentation jointly with one fused Gromov–Wasserstein model; CLOT is from the same lab as DELTA.

TCC (CVPR '19) · LAV / VAVA (CVPR '21–'22) · GTCC (CVPR '23) · Temporally-Consistent Unbalanced OT (CVPR '24) · CLOT (ICCV '25) · Joint SSL Align+Seg (ICCV '25)

Vision-language & video foundation features

No one has reported an I3D → FM swap for transcript-only DLTA. VideoLLaMA 3's vision tower ships standalone (VL3-SigLIP-NaViT, ~1152-d, any-resolution). DINOv2 is the pure-vision ablation; procedure-aware pretraining (StepFormer, Zhong '23) learns the step structure we want.

VideoLLaMA 3 · InternVideo2 · SigLIP 2 · DINOv2 · Procedure-aware repr. (CVPR '23) · StepFormer (CVPR '23)

Language / LLM priors for LTA — adjacent

Symbolic future-action prediction with language priors. Complementary to DELTA's dense forecast; a possible late add-on (an LLM prior over T*), not this phase.

PALM (ECCV '24) · Plausible LVLM anticipation (CVPR '24) · ObjectPrompt (WACV '24)

04 — Plan

Four phases, gated on alignment quality

Swap I3D + DistilBERT for a paired VL foundation model, then replace DELTA's greedy DP alignment with a self-supervised, OT-based, monotonicity-constrained transcript → frame alignment trained jointly with the encoder. Evaluate first by alignment / segmentation quality on 50Salads, then by downstream DLTA.

Foundation-model features done — this repo

delta.features.extract emits (D, T) per video with T = len(groundTruth) — a drop-in replacement for I3D. Backbones: vl3-siglip (default), siglip2, dinov2, i3d-compat (parity). Text via the SigLIP-2 tower (same space) or DistilBERT (parity).

Drop-in swap — measure alignment quality next

Re-run TA + TAS with each feature set, everything else fixed. Score Y* against ground truth on the observed part (MoF · MoC · edit · F1@{10,25,50} + boundary offset + τ-alignment across same-activity videos).

  1. Grid: {I3D, VL3-SigLIP, SigLIP2, DINOv2} × {DistilBERT, SigLIP2-text}.
  2. Isolates: do better features alone fix 50Salads alignment?
  3. Needs a DELTA re-implementation — no official code yet; ATBA + FUTR / ActFusion are public starting points.
Multimodal self-supervised alignment objective

Added to the TA stage, in order of payoff / risk. CTC and the CRF stay untouched — they are complementary.

  1. Contrastive transcript-step ↔ frame-window (InfoNCE with Y* as soft assignment) — makes the crossmodal grounding a real similarity. Cheap, low-risk.
  2. OT alignment decoder with a monotonicity prior (fused Gromov–Wasserstein), re-solved each iteration — removes the "one early error propagates" failure mode.
  3. Cross-video temporal cycle-consistency among same-activity videos — a shared monotone phase representation.
  4. VLM pseudo-supervision — zero-shot VideoLLaMA-3 scoring of frame windows against the transcript vocabulary. Higher cost, precompute offline.
Downstream DLTA

Feed the improved alignment into DELTA's two-stage schedule. Evaluate the standard grid — observe 20 / 30 %, predict 10 / 20 / 30 / 50 %, five splits, MoC. Target: close the gap to ActFusion (28.4) on 50Salads with no regression on Breakfast.

06 — Risks & open questions

What could stall this

  • No official DELTA code. Re-implementation is on the critical path — ask whether the authors will share it.
  • Kaggle mirrors. Confirm the 50Salads features are I3D (not IDT) and the label fps (15 vs 30) before trusting the config; raw video may need the official Dundee download.
  • VL3-SigLIP throughput. ~0.5–1 M frames for 50S at 15 fps — fine on the cluster with the provided SLURM array; window mode multiplies cost.
  • Duration stays ill-posed from transcripts — acknowledged in the paper, not a target of this phase.
  • Fair comparison. Swapping features shifts the input distribution vs published I3D numbers — always report an I3D re-run under our own code as the control.
  • Open: deterministic only for now, or also the stochastic best-of-sample protocol? (Notes say alignment first → deterministic.)
